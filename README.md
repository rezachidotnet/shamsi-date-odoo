# Shamsi Date for Odoo

- Repository: `shamsi-date-odoo`
- Current Odoo technical module: `sale_shamsi_report`
- Odoo target: 19.0
- Manifest name: Sale Shamsi Dates
- Manifest version: 1.0
- Odoo dependencies: `sale`, `portal`, `website`, `sale_stock`, `mail`, and `calendar`
- Python dependency: `jdatetime`

This addon adds computed Jalali/Shamsi date text to Sale orders and displays it in Sale forms, reports, and portal pages. Its frontend assets also add Jalali date displays to selected Odoo calendar, messaging, scheduling, list, and vendor price-list interfaces.

This repository starts from the existing production baseline of the standalone addon. The Odoo technical module remains `sale_shamsi_report`.
